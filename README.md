# Wrapora

Wrapora is a modern gifting website built with Next.js, React, TypeScript, and Tailwind CSS. The project focuses on creating a clean, responsive, and user-friendly interface for discovering and exploring gifts.

## Features

- Responsive homepage
- Hero slider/banner
- Best Sellers section
- Product cards with pricing, ratings, and reviews
- Promotional sections
- Responsive navigation
- Search interface
- User registration and login
- Firebase Authentication
- User profile/account page
- Responsive design for desktop, tablet, and mobile
- Reusable React components
- Next.js Image optimization
- Redux Toolkit for state management
- RTK Query for API data fetching

## Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/wrapora.git
```

### Navigate to the project directory

```bash
cd wrapora
```

### Install dependencies

```bash
npm install
```

### Environment Variables

Create a `.env` file in the project root and add the required Firebase environment variables.

```env
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_auth_domain
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_storage_bucket
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
```

Do not commit `.env` to the repository.

### Start the Development Server

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Production Build

Create a production build:

```bash
npm run build
```

Run the production application:

```bash
npm start
```
